# Titanic Dataset Profiling with Pandas

A beginner-friendly Pandas project that explores the classic Titanic dataset and creates an interactive HTML profiling report with YData Profiling.

## Project Overview

This project demonstrates the basic workflow of loading tabular data, checking its structure, viewing sample rows, calculating summary statistics, and generating a profiling report. It is intended as a portfolio project for someone learning Python and Pandas.

No machine-learning model or synthetic dataset is used.

## Objectives

- Load the Titanic CSV file into a Pandas DataFrame
- Explore rows, columns, data types, and missing values
- View the first and last records
- Calculate and interpret descriptive statistics
- Generate an HTML report with YData Profiling
- Present the work clearly for a GitHub portfolio

## Dataset Description

The original Titanic dataset is a tabular passenger dataset commonly used for data-analysis practice. The notebook expects the original CSV to be stored at:

```text
data/titanic.csv
```

**The CSV is currently missing from this project.** It must be obtained from an appropriate source before the notebook can be executed. Do not add or generate substitute passenger data under the same filename. Confirm the dataset's redistribution permission before committing it to GitHub.

The saved outputs in the notebook show 891 rows in the existing statistical summary and 714 non-null `Age` values.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/khawarkngithub/Pandas-Profiling.git
cd Pandas-Profiling
```

2. Create and activate a virtual environment:

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

3. Install dependencies:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

4. Place the original `titanic.csv` file in the `data` directory.

## How to Run the Notebook

Start Jupyter:

```bash
jupyter notebook
```

Open `notebooks/pandas-profiling.ipynb`, select the notebook kernel, and choose **Run All**. The notebook can also be run from VS Code with a Jupyter-enabled Python environment.

The loading code works from both the project directory and the `notebooks` directory. It stops with an explicit `FileNotFoundError` if `data/titanic.csv` is absent instead of pretending that a dataset was loaded.

## How to Generate the HTML Report

Run the YData Profiling section of the notebook. It creates:

```text
reports/titanic_profiling_report.html
```

The report is generated by:

```python
profile = ProfileReport(
    df,
    title="Titanic Dataset Profiling Report",
)
profile.to_file("reports/titanic_profiling_report.html")
```

Open the generated HTML file in a browser to review the report.

## YData Profiling Package Note

The project currently uses `ydata-profiling` consistently for installation and `from ydata_profiling import ProfileReport` for importing.

Some recent YData package versions show a deprecation notice recommending a migration to the successor package `fg-data-profiling` and `data_profiling`. This project intentionally does not mix old and new package names. Before migrating, test the successor package in a separate environment and update the requirement and notebook import together.
